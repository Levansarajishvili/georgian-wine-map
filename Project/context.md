# საქართველოს ღვინის რუკა — პროექტის კონტექსტი
ბოლო განახლება: 2026-11-18 (ეტაპი 8)

## რა არის
ინტერაქტიული ღვინის რუკა, Map_2 პროექტის გაგრძელება. რუკაზე ჩანს საქართველოს რეგიონები, ღვინის ზონები რეალური საზღვრებით (პოლიგონები, არა წერტილები), ვაზის ჯიშები და ღვინის სტილის ფილტრი.
აუდიტორია: ტურისტები და ღვინის მოყვარულები, მათ შორის ისინი, ვინც ჯიშების სახელებს არ იცნობს და „ქარვისფერ ღვინოს“ ეძებს.

## ფარგლები (v1)
- შედის: რეგიონები (ADM1), ღვინის ზონები, ჯიშები, სტილები, ფილტრი, ზონის პანელი, რეგიონების სია, mobile-first, WCAG 2.2 AA.
- ჯერ არ შედის: ინგლისური ვერსია, მარნები, ბექენდი, მუქი თემა.

## სტეკი
Vite + React (JS), OpenLayers (ol), EPSG:3857. მონაცემები სტატიკური GeoJSON/JSON ფაილებია.
საბაზისო ფენები (ეტაპი 4): ხუთი სლოტი `src/map/basemaps.js`-ში, ხუთივე გასაღებისა და გადახდის გარეშე იტვირთება: `light` OpenStreetMap.de (ფერადი რუკაა, არა ნაცრისფერი ღია ფონი), `humanitarian` Humanitarian (HOT) სტილი OpenStreetMap France-ის სერვერიდან (დამატდა 2026-11-19), `terrain` OpenTopoMap, `imagery` Esri World Imagery. `light` geohowtos.com-ის XYZ სიიდანაა, `humanitarian` მომხმარებლის მოწოდებული ჩანაწერია, `terrain` და `imagery` სიის წყაროდან (leaflet-providers 4.0.0); URL და attribution უცვლელადაა ჩაწერილი. მეხუთე სლოტი `hybrid` Google-ის სატელიტია წარწერებით, პირდაპირი XYZ მისამართით (დამატდა 2026-11-19 მფლობელის გადაწყვეტილებით; Google-ის პირობებს არ შეესაბამება და დოკუმენტირებული API არ არის). ნაგულისხმევი ფენა (გვერდის გახსნისას ხილული; `DEFAULT_BASEMAP_ID`) 2026-11-19-დან `hybrid`-ია, მანამდე `light` იყო. პირობები: 06-data-sources.md §8.
შრიფტი: FiraGO 400/500, self-host, subset woff2 (ქართული + ლათინური, ≈ 37 KB თითო წონა).
განთავსება: Netlify ან Vercel, SPA redirect-ით URL-ფილტრებისთვის.
ტესტები: Vitest (`npm test`), `domain/`-ის სუფთა ფუნქციებზე (ეტაპი 6) და `components/BottomSheet/snapPoints.js`-ზე (ეტაპი 8), node გარემოში.

- ძებნის ველი ყველა ეკრანზეა, სინონიმების მინიშნებით („დაემთხვა: orange wine“).

- რამდენიმესტილიანი ზონა: ერთი ფერი წესით (სტილი ყველაზე პატარა `order`-ით). სტილის ფილტრისას ზონა მონიშნული სტილის ფერს იღებს. labelPoint-ზე ჩიპი ყველა სტილს აჩვენებს. 02-data-model.md არ იცვლება.

Headless Chrome-ში ჰიბრიდის ფენაზე ორივე რეგიონზე შემოწმდა; სხვა ფენებზე სანახავია. კოდი: `regionsLayer`, `regionStyle`, `interactions.attachRegionHover` (01 §3).
- რეგიონული ცენტრის ნიშანი რუკაზე (2026-11-19, მფლობელის მოთხოვნით): რეგიონის ადმინისტრაციულ ცენტრზე (კახეთი → თელავი, რაჭა-ლეჩხუმი და ქვემო სვანეთი → ამბროლაური) ლოკაციის ნიშანი ზის, მუდმივად, hover-ის გარეშეც. ნიშანი მელნისფერია თეთრი casing-ით და თეთრი წერტილით (`--map-region-center-*` ტოკენები 03-tokens.css-ში): ღვინის ფერს და UI-ის აქცენტს არ იმეორებს, რადგან არც ზონაა და არც ღილაკი. ცალკე შრეა ზონების ზემოთ; hover-ის იერი არ აქვს და ფილტრი მასზე არ მოქმედებს. ქალაქის სახელი მონაცემშია (`center.name`) და ნიშანზე დაკლიკებისას popup-ში იწერება (შემდეგი პუნქტი). მონაცემი: `regions.json`-ის ახალი არასავალდებულო ველი `center` (`name`, `point`, საკუთარი `source` და `verified`; 02 §4.4), წყარო `osm-places`. Headless Chrome-ში შემოწმდა (build, 1280×800 და 3x სიმკვრივე): ორივე ნიშანი იხატება, წვერი წერტილზეა; tile-ები იქ არ ჩაიტვირთა, ამიტომ ნიშნის კონტრასტი ნამდვილ ფენებზე სანახავია. კოდი: `regionCentersLayer`, `regionCenterStyle`, `loaders/geometry.createRegionCenterFeatures` (01 §3).
- რეგიონული ცენტრის popup (2026-11-19, მფლობელის მოთხოვნით): ნიშანზე დაკლიკება (ან შეხება) ნიშნის ზემოთ ხსნის პატარა ფირფიტას ქალაქის სახელით („თელავი“). ერთი popup-ია მთელ რუკაზე: სხვა ნიშანზე დაკლიკება მას იქ გადაიტანს; იმავე ნიშანზე ხელახლა ან რუკის ნებისმიერ სხვა ადგილას დაკლიკება ხურავს; თავად ფირფიტაზე დაკლიკება არაფერს ცვლის. ნიშანი ზონების ზემოთაა, ამიტომ დაკლიკებას ნიშანი იღებს: მის ქვეშ მყოფი ზონა ამ დროს არც ირჩევა და არც hover-ით ინიშნება, არჩეული ზონა კი არჩეული რჩება. ნიშანზე cursor `pointer`-ია. კიდესთან მდგარი ნიშნის popup-ისთვის რუკა ოდნავ გადაიწევს (`--motion-duration-map`, reduced motion-ზე ანიმაციის გარეშე). ფირფიტა DOM ელემენტია (`ol/Overlay`), იერი `global.css`-ის `.map-popup`-შია არსებული ტოკენებით: სახელი 22px-ია (`--font-size-xl`), padding 12px / 24px. გახსნისას ფირფიტა 3 წამში ქვემოდან ამოდის (24px, `translateY`) და მკვეთრდება (`opacity` 0 → 1); ხანგრძლივობა მფლობელის არჩევანია (`--motion-duration-popup: 3s`, reduced motion-ზე 1ms). ანიმაცია ყოველ გახსნაზე თავიდან იწყება, ნიშნიდან ნიშანზე გადატანისასაც (`.map-popup-entering`). ახალი ტოკენები: `--map-region-center-popup-gap` და `--motion-duration-popup`. React-ამდე არ მიდის.
