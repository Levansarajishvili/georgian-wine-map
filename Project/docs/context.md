# საქართველოს ღვინის რუკა — პროექტის კონტექსტი
ბოლო განახლება: 2026-11-18

## რა არის
ინტერაქტიული ღვინის რუკა, Map_2 პროექტის გაგრძელება. რუკაზე ჩანს საქართველოს რეგიონები, ღვინის ზონები რეალური საზღვრებით (პოლიგონები, არა წერტილები), ვაზის ჯიშები და ღვინის სტილის ფილტრი.
აუდიტორია: ტურისტები და ღვინის მოყვარულები, მათ შორის ისინი, ვინც ჯიშების სახელებს არ იცნობს და „ქარვისფერ ღვინოს“ ეძებს.

## ფარგლები (v1)
- შედის: რეგიონები (ADM1), ღვინის ზონები, ჯიშები, სტილები, ფილტრი, ზონის პანელი, რეგიონების სია, mobile-first, WCAG 2.2 AA.
- ჯერ არ შედის: ინგლისური ვერსია, მარნები, ბექენდი, მუქი თემა.

## სტეკი
Vite + React (JS), OpenLayers (ol), EPSG:3857. მონაცემები სტატიკური GeoJSON/JSON ფაილებია.
საბაზისო ფენები (ეტაპი 4): სამი სლოტი `src/map/basemaps.js`-ში, სამივე გასაღებისა და გადახდის გარეშე იტვირთება: `light` OpenStreetMap.de (ფერადი რუკაა, არა ნაცრისფერი ღია ფონი), `terrain` OpenTopoMap, `imagery` Esri World Imagery. `light` geohowtos.com-ის XYZ სიიდანაა, დანარჩენი ორი მისი წყაროდან (leaflet-providers 4.0.0); URL და attribution უცვლელადაა ჩაწერილი. Google-ის tile-ები პირდაპირი XYZ მისამართით არ გამოიყენება. პირობები: 06-data-sources.md §8.
შრიფტი: FiraGO 400/500, self-host, subset woff2 (ქართული + ლათინური, ≈ 37 KB თითო წონა).
განთავსება: Netlify ან Vercel, SPA redirect-ით URL-ფილტრებისთვის.

## მიღებული გადაწყვეტილებები

- შეუსაბამო ზონები ჩამქრალია და არა დამალული.

- ზონების შრე რეგიონების შრის ზემოთაა. პატარა პოლიგონი დაბალ zoom-ზე ცენტროიდის მარკერად ჩანს.
- მობილურზე ფილტრი და პანელი bottom sheet-ია: ერთი კონტეინერი, სამი რეჟიმი (სია ნაგულისხმევია, ფილტრი, ზონა), მდგომარეობები ჩაკეცილი / ნახევრად / სრული. desktop-ზე იგივე გვერდითი პანელია. დეტალები: 05-ui-spec.md.
- ძებნის ველი ყველა ეკრანზეა, სინონიმების მინიშნებით („დაემთხვა: orange wine“).
- ვიზუალური მიმართულება: „საველე ატლასი“. ტოკენები: 03-tokens.css, ფერის, spacing-ის, radius-ისა და შრიფტის ერთადერთი წყარო. UI-ის აქცენტი მელნის ლურჯია და ღვინის ფერებს არ იმეორებს.
- რამდენიმესტილიანი ზონა: ერთი ფერი წესით (სტილი ყველაზე პატარა `order`-ით). სტილის ფილტრისას ზონა მონიშნული სტილის ფერს იღებს. labelPoint-ზე ჩიპი ყველა სტილს აჩვენებს. 02-data-model.md არ იცვლება.

- ჯიშის ბმული ზონის პანელში ფილტრს მხოლოდ ამ ჯიშზე აწყობს (სტილი იშლება), ამიტომ შედეგი არასოდეს არის 0.
- საბაზისო ფენას გადახდა და API გასაღები არ უნდა სჭირდებოდეს (2026-11-18). რელიეფისთვის Google-ის პირდაპირი მისამართის ნაცვლად OpenTopoMap აირჩა.

## ღია საკითხები
- ზონების გეომეტრია (ჩატი 3; კვლევა დასრულდა, არჩევანი ღიაა): ზონების მზა ღია GIS მონაცემი და სოფლების ტერიტორიების ღია პოლიგონები ვერ მოიძებნა (OSM-ში სოფელი ადმინისტრაციული ერთეული არ არის). წინადადება `village-voronoi`: OSM-ის სოფლების წერტილები → Voronoi → მუნიციპალიტეტით დაჭრა → ზონის სოფლების dissolve; `boundary.method: "village-voronoi"`, `boundary.verified` ყოველთვის false. მიახლოება „რეალური საზღვრების“ მიზანს სრულად ვერ აკმაყოფილებს, ეს UI-ში უნდა ჩანდეს (ეტაპი 7). მომავლის ალტერნატივა: ღვინის ეროვნული სააგენტოს ვენახების კადასტრი საჯარო ინფორმაციის გამოთხოვით. დეტალები: 06-data-sources.md §5.
- ADM1-ის წყარო (ჩატი 3; არჩევანი ღიაა): geoBoundaries (ODbL), OSM პირდაპირ (ODbL) ან COD-AB/საქსტატი (სავარაუდოდ CC BY-IGO, შესამოწმებელი). GADM გამორიცხულია: მხოლოდ არაკომერციული გამოყენება, გავრცელება აკრძალულია. დეტალები: 06-data-sources.md §1–2.
- აფხაზეთისა და ცხინვალის რეგიონის ჩვენება (არჩევანი ღიაა): ა. ADM1 + სტატუსი; ბ. ორივე ცალკე, შტრიხით; გ. ნეიტრალური. ტერმინები „ოკუპირებული ტერიტორიების შესახებ“ კანონის მე-2 მუხლით. დეტალები: 06-data-sources.md §4.
- საბაზისო ფენები (ეტაპი 4; ფენები არჩეულია, დეტალები ღიაა): `light` სლოტში OpenStreetMap.de ფერადი რუკაა გერმანული და ადგილობრივი წარწერებით: რჩება თუ დროებითია, და გადამრთველში „ღია ფონი“ ეწერება თუ „სტანდარტული“. Esri World Imagery გასაღების გარეშე იტვირთება, მაგრამ Esri-ის პირობები უფასო ანგარიშს და „Powered by Esri“-ს გულისხმობს; პირველწყაროში წასაკითხია. დეტალები: 06-data-sources.md §8.
- `src/data/regions.geo.json` placeholder-ია (02 §4.4, კოორდინატები (0, 0)-თან): ნამდვილ ADM1 გეომეტრიამდე რუკა გვინეის ყურეში იხსნება. რეგიონების მონაცემის attribution რუკაზე ჯერ არ ჩანს: ADM1-ის წყაროს არჩევანს ელოდება.
- `src/data/zones.geo.json` placeholder-ია (02 §4.5-ის ნიმუში, ეტაპი 5): ნაფარეული და ხვანჭკარა ერთი და იგივე კვადრატია (0, 0)-თან, ამიტომ რუკაზე ერთი მარკერი ჩანს (ნაფარეული ზემოთაა) და ხვანჭკარა რუკიდან ვერ აირჩევა. ნამდვილი გეომეტრია ჩატ 3-ის ღია არჩევანს ელოდება (06 §5).
- 01-architecture.md-ის დამატებები ეტაპ 4-იდან დასადასტურებელია (01 §10): `MapContext.js` ცალკე ფაილად; layout-ის ცვლადი `--map-inset-bottom`; გლობალური კლასი `.map-button`; Zoom და Attribution კონტროლები `target`-ით; `loaders/geometry` აბრუნებს `{ features, extent }`; zoom 5–15 და გამორთული როტაცია; ESLint flat config; `MapContext`-ის არე RegionList-ისთვის.
